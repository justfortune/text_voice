## Совместимость recovery2 по диагностике установленной версии

- Принимается проверяемое старое состояние «часть закреплена, у фразы снят индивидуальный locked, выбран сохранённый дубль». Флаг части и явный выбор сохраняются без создания нового индивидуального закрепления.
- Защита конвейера охватывает весь закреплённый диапазон. Выбранные WAV/JSON включаются в проверку наличия, снимок подготовки и контроль обслуживания голосов.
- Автоматическая проверка тишины и перепривязка UID сохраняют legacy-выбор; ручные set/choose остаются доступны. Общая схема привязки вставок сохраняет эту защиту после save, включая вставку за последней исходной фразой части.
- Три отличающихся исходных файла изучены отдельно и допущены по точным нормализованным SHA-256. Локальный выбор `envfast` книги для редакторского движка сохранён.
- Проверка активных процессов предшествует чтению состояния и созданию диагностического снимка. Пауза интерфейса не считается закрытием Studio.
- Изменение метаданных во время проверки останавливает её; несколько независимых несовместимостей показываются вместе.
- Добавлены регрессионные проверки старой схемы закреплений и отдельная приёмка обновления/отката на временной копии фактических документов с явно синтетическими аудиофайлами.

## Защита существующей книги

- Строгая сверка `fixed_parts.json` и `edits.json`, настоящих UID/границ, вставок, склеек и отдельных закреплений.
- Сохранение закреплённого начала при изменении нарезки; остановка при изменении защищённого содержания и неоднозначном переносе ссылок.
- Проверяемые снимки подготовки, история входов, защита от параллельной правки и восстановление прерванных публикаций.
- Сохранение прежних WAV с техническим текстом/метаданными перед отбраковкой или сменой редакции.
- Повторная проверка защиты в проверяющем процессе и воркерах перед изменением файлов.

## Studio

- Транзакции WAV/JSON/правок, файловая отмена, восстановление после прерывания.
- Согласованное снятие закрепления фразы/части и восстановление дублей из проекта/корзины.
- Несколько вырезов, явные пустые/одиночные интервалы, перенос остатка в следующую фразу, сброс/удаление.
- Просмотр прежней озвучки с проверкой происхождения, ручным выбором и ограниченным однозначным автоматическим присоединением.
- Ограниченный обход и обновление внешнего звукового каталога, разделы/подразделы, поиск и страницы результатов.
- Обычный запуск f9 не создаёт лишнюю модель во время подготовки `go`; готовность подтверждается после прогрева.

## Экспорт и обслуживание

- Согласованная публикация голоса, звуковых вариантов, сопроводительных файлов и отметки экспорта.
- Раздельный результат копирования аудио и резервных метаданных на локальный Яндекс Диск; уникальные временные файлы, повтор временного отказа Windows.
- Очистка дублей в обоих режимах обратима; без дополнительной копии больше не означает безвозвратное удаление WAV.
- Отдельные инструменты обслуживания используют проверяемый карантин, план и восстановление; не завершают процессы и не перебирают чужие Downloads.
- Уборка образцов голосов сохраняет WAV/TXT/JSON одной операцией, учитывает закреплённые и исторические ссылки, восстанавливает прежние роли и банк после сбоя.
- Восстановление подготовки и голосовых операций проверяет PID на Windows через API чтения состояния; проверка не вызывает завершение процесса.
- Код обновляется целым комплектом по SHA-256, с проверкой локальной совместимости, резервированием и ограниченным откатом.
- Установленный комплект имеет явный путь; запуск не выбирает случайный файл по времени скачивания.
- Старые готовые аудиофайлы остаются до успешной пересборки вместо предварительного удаления.

## Сохранённые ограничения

Установленная у пользователя итерация 12b должна пройти проверку хешей. Новые файлы ролей/рукописи из другой редакции не применяются автоматически. Качество конкретного голоса и правильность каждого ударения проверяются прослушиванием. Старое окончательно удалённое аудио не восстанавливается из одной только переписки.
