# NOX 18d — соответствие требованиям и локальная приёмка

Этот реестр охватывает все 45 требований, выделенных при повторном разборе активной `main` и архивной переписки. Он описывает **фактическую интеграцию новой сборки**, а не подтверждает существование или точное содержимое исторического ZIP 18d.

В таблицах отдельно указаны сохранённые функции `main`, внесённые исправления, область автоматической проверки и то, что нужно принять на целевом ПК. Наличие функции и успешные проверки файловых операций не доказывают художественное качество голоса, правильность каждой роли или отсутствие ошибок во всей книге.

## Как читать ссылки на проверки

Все имена ниже относятся к каталогу `tests` этого комплекта. Количество тестов здесь не фиксируется: окончательный протокол формируется из фактического прогона собранного архива.

| Обозначение | Семейство проверок и его пределы |
|---|---|
| **P** | `protection_regressions.py`: реальные схемы UID/закреплений, подготовка CSV, публикация метаданных, сформированный патч конвейера, границы работы воркера. Без TTS/GPU. |
| **V** | `protection_voice_and_publish.py`: действующие команды кастинга, таблицы ролей и проверки голосов, защита используемых образцов и публикации. Модельные вычисления заменены контролируемыми фикстурами. |
| **B** | `backend_studio.py`, `backend_transactions.py`, `backend_integration.py`, `backend_voice_tidy.py`: методы Studio, реальные временные файлы, устойчивые транзакции, HTTP-контракты, история записей и каталог; действующая команда уборки голосов, предварительный просмотр без изменений, откат файлов и метаданных, восстановление после прерывания и защита исторических ссылок. |
| **F** | `frontend_contracts.cjs`: фактический встроенный JavaScript и обработчики с DOM/HTTP-стендом. Это проверка поведения контроллеров, не визуальная или акустическая приёмка браузера. |
| **E** | `installer_export_integration.py`: действующая цепочка экспорта части/главы, связанных файлов, правок и копирования; кодирование звука заменено фикстурой. |
| **U** | `installer_release_safety.py`, `installer_final_integration.py`: совместимость кода, хеши, области назначения, точный откат, полный комплект и первоначальная установка приложения. PowerShell проверяется статически, не исполняется на Windows. |
| **A** | `installer_archive_verifier.py`: сохранение прежних WAV и сопутствующих файлов, прерывания, повторная проверка владения записью перед отбраковкой. |
| **M** | `maintenance_safety.py`: план очистки, карантин, полный возврат, NoBackup, процессы, защита и отказ до частичного изменения. |
| **G** | `publishing_safety.py`: сборка и публикация только разрешённого кода, ограничения активной `main`, контроль приватных данных; используются временные Git-репозитории. |

## Итоговая граница приёмки

Автоматические проверки предназначены прежде всего для подтверждения сохранности данных, правильности контрактов и воспроизводимых отказов. Они не являются заменой запуска на пользовательской Windows, проверки драйвера/GPU, прослушивания и сверки актуальной редакции книги.

Обновление неизвестной локальной версии должно останавливаться с диагностикой, а не угадывать подходящий исходник. Неоднозначная прежняя запись должна оставаться для ручного сравнения. Повреждённое закрепление или незавершённая транзакция должны сохранять исходные файлы и объяснять причину остановки.
