# Интерфейс 18d: интеграция и границы проверки

Изменения внесены в исходный `kit/nox_studio.html` активной `main`. Поздние команды из переписки 18c/18d использованы как источник замысла, а обнаруженные ошибки передачи данных исправлены в интегрированном коде. Это новая инженерная сборка, не побайтно восстановленный отсутствующий исторический ZIP.

## Реализовано

| Задача | Поведение интегрированного интерфейса |
|---|---|
| Несколько вырезов из дубля | Вырезы объединяются при пересечении; сохраняются точные оставшиеся интервалы. Один оставшийся интервал передаётся явно. Если звук вырезан полностью, сохранение и перенос хвоста останавливаются до запроса к серверу. |
| Продолжение следующей фразы | Передаются все оставшиеся интервалы и конец последнего из них. После успешного переноса открывается редактор следующей фразы; при ошибке текущий редактор остаётся доступным. |
| Сброс обрезки | Отдельно сбрасываются вырезы и вся обрезка. Отмена жеста указателя не добавляет случайный вырез. |
| Прежняя озвучка | Показываются исходный текст, роль, происхождение и ограничения совпадения; есть прослушивание, добавление без выбора и ручной выбор. Неоднозначное или технически неподтверждённое совпадение требует явного подтверждения при выборе. |
| Длинная история | Страницы по 100 записей с переходами вперёд и назад; ошибки чтения части истории показываются отдельно. Архивы конвейера, которые отдаёт backend, отличаются от старых дублей Studio. |
| Автоматический возврат | Отдельное явно вызываемое действие. Условия безопасного совпадения проверяет backend: текст, роль, технический текст и уникальность. Интерфейс не выдаёт похожесть за доказанное соответствие. |
| Каталог звуков | Русские разделы/подразделы, поиск, прослушивание, выбор, подключение внешней папки, обновление индекса. Пагинация по 80 сохраняет фильтры. При ограниченном обходе каталога это прямо указано. |
| Выбор типа дорожки | При выборе звука сохраняются тип и длительность; вставка в эффекты, фон или музыку делается явно. |
| Сброс и очистка фразы | Отдельные действия сброса правок и удаления дублей со сбросом. Последнее точно сообщает, что черновик конвейера остаётся; перед запросом запрашивается подтверждение. |
| Очистка дублей с копией/без | Обе пользовательские возможности сохранены. Различие — дополнительная копия проекта. В обеих вариантах backend сохраняет транзакционную корзину и Undo; интерфейс не обещает безвозвратное стирание. Это изменённая, более безопасная семантика прежнего варианта без копии. |
| Несохранённая правка текста | Ошибка сохранения сохраняет признак несохранённого текста и блокирует последующую новую файловую операцию над фразой. |
| Звуковые отметки всех доступных частей | Отдельная команда полного прохода; после неё текущая часть перечитывается корректным GET-запросом. |
| Движок и число воркеров | Отдельно показаны воркеры книги и редактора. Во время прогрева конвейера интерфейс ждёт его воркеров. Число 1500 подписано как лимит токенов следующего запуска, а не размер батча. |

Имеющиеся функции `main` — работа по частям, закрепление, текстовые вставки, проекты, экспорт, горячие клавиши, выбор и прокрутка фраз — сохранены. Новая разметка не подменяет всё приложение отдельным макетом.

## Что проверено

`tests/frontend_contracts.cjs` исполняет весь фактический встроенный JavaScript до стартового цикла опроса. Используются небольшой DOM-стенд и HTTP-фикстуры; тесты вызывают реальные функции и обработчики интерфейса. **20 из 20 проверок пройдены.**

Проверены случаи 0/1/нескольких оставшихся интервалов, успешный и неуспешный перенос хвоста, восстановление сохранённой обрезки, отмена жеста, фильтры/пагинация/обновление звуков, безопасное экранирование названий, оригинальный текст и кодирование идентификаторов старых записей, подтверждение неоднозначного выбора, длинная/частично повреждённая история, кнопки закреплённых фраз, отмена очистки, несохранённый текст, обе формы очистки дублей, обновление отметок и счётчик движка.

Отдельно подготовлен `tests/frontend_ui.cjs` для настоящего Chromium/Playwright. В этой среде Chromium не смог стартовать из-за запрета системного `socket()` (`Operation not permitted`) ещё до открытия страницы. Поэтому визуальная раскладка, реальное воспроизведение звука, физические жесты мыши и работа Windows-браузера **не объявляются проверенными**. Этот runner сохранён для среды, в которой Chromium можно запускать.

## Ограничения, которые нельзя скрывать

- Логи и тесты контроллеров не заменяют прослушивание голоса, ударений и монтажа на целевом ПК.
- Сохранение исторических данных, разрешение коллизий и условия автоматического возврата обеспечиваются backend. Клиент не может самостоятельно подтвердить происхождение отсутствующего WAV.
- Предложенный в переписке второй таймлайн был вариантом интерфейса сравнения. Здесь цель реализована карточками текущего/исходного текста, прослушиванием и отдельным выбором записи; отдельного второго таймлайна нет.
- Карантин обслуживания из `nox_maintenance.py` восстанавливается полным комплектом; он пока не индексируется в диалоге отдельных прежних записей.
- Ни эти проверки, ни запуск тестов установщика не выполняли обновление рабочей книги пользователя или публикацию в GitHub.
